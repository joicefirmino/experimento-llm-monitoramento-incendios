# Experimento com LLMs – Monitoramento e Mapeamento de Focos de Incêndios

## Sobre o projeto

Este repositório reúne os materiais utilizados no experimento acadêmico de análise de recomendações geradas por Modelos de Linguagem de Grande Escala (LLMs), aplicados ao projeto **Monitoramento e Mapeamento de Focos de Incêndios**.

O objetivo do experimento é utilizar diferentes inteligências artificiais para sugerir melhorias na interface e na experiência do usuário (UX) do sistema, considerando aspectos como usabilidade, acessibilidade, organização das informações e funcionalidades.

## Objetivo do experimento

Comparar as recomendações apresentadas por diferentes modelos de inteligência artificial, analisando as melhorias sugeridas para o projeto e identificando possíveis contribuições para o desenvolvimento do sistema.

 ## Modelos utilizados

- Gemini
- GPT (ChatGPT)
- DOLA
- DeepSeek

## Organização do repositório

**01-Prompt/**

Contém o prompt utilizado nas interações com os modelos de inteligência artificial.

**02-Respostas-LLMs/**

Contém os arquivos com as respostas geradas pelos quatro modelos utilizados no experimento.

## Considerações finais

O experimento permite observar diferentes sugestões de melhorias para o sistema, contribuindo para a análise e escolha de funcionalidades que possam melhorar a experiência dos usuários.
